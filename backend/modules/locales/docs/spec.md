# Locales module (reference language pack)

Optional product module that ships **pl**, **de**, and **fr** UI catalogs.
English remains in `modules/base/i18n/en.json`.

- `auto_install: true` — enabled by default in dev/demo stacks.
- Disable via **Settings → Module catalog** to run English-only.
- Copy this layout when adding `es`, `it`, etc. in your own module.
